# Computational and Biological Intelligence — runnable Python learning modules

Nine notebooks and 80 standalone Python scripts that teach the core methods of computational intelligence through medical and biomedical examples: machine learning, neural networks, convolutional networks for medical images, classic algorithms, fuzzy systems, evolutionary computing, and hybrid ANFIS systems.

The materials accompany the textbook *Computational and Biological Intelligence: From Machine Learning to Neural Networks, Fuzzy Systems, and Evolutionary Computing — With Practical Examples in Python* by Amir Movasagh. They can also be used on their own.

## Who this is for

- Senior undergraduate and graduate students in biomedical engineering, medical physics, and health informatics.
- Students of computer science and electrical engineering who want medical applications.
- Instructors who want ready, tested examples for a one-semester course on computational intelligence or soft computing.

Prerequisites: basic calculus, linear algebra, and probability. No prior Python experience is assumed; `appendix_A` covers what is needed.

## What is inside

| Folder | Topic | Examples |
|---|---|---|
| `chapter_1` | Fundamentals: supervised, unsupervised and reinforcement learning; data splitting; under- and overfitting; early stopping | 1.1 – 1.11 |
| `chapter_2` | Artificial neural networks: neuron, activation and loss functions, gradient descent, optimisers, backpropagation from scratch, regularisation | 2.1 – 2.11 |
| `chapter_3` | Machine vision and medical imaging: convolution and pooling by hand, classic pipelines, HOG, VGG-16, simulated radiography and CT reconstruction, Hounsfield units | 3.1 – 3.12 |
| `chapter_4` | CNNs and FCNs in medicine: feature-map arithmetic, a CNN with backpropagation in NumPy, K-fold validation, augmentation, upsampling, pixel-wise segmentation, occlusion maps, a CNN and a small U-Net in PyTorch | 4.1 – 4.10 |
| `chapter_5` | KNN, k-means, decision trees, SVM and random forest on medical data | 5.1 – 5.11 |
| `chapter_6` | Fuzzy systems: fuzzy sets and operators, Mamdani and Sugeno inference, fuzzy c-means, fuzzy relations for diagnosis | 6.1 – 6.9 |
| `chapter_7` | Genetic algorithm (including feature selection), PSO, ANFIS with hybrid learning, differential evolution, and a case study tuning an SVM for breast-cancer diagnosis | 7.1 – 7.6 |
| `appendix_A` | Python for data science: NumPy, Matplotlib, Pandas | A.1 – A.6 |
| `appendix_B` | Evaluation metrics in medicine: confusion matrix, ROC/AUC, regression and segmentation metrics, imbalanced data | B.1 – B.4 |

Each folder contains one notebook (for example `chapter_4/chapter_4.ipynb`) that lists the learning objectives and runs all the examples of that chapter in order, and one script per example (for example `chapter_4/example_4_2.py`), named after its number in the book.

Most algorithms are first written from scratch in NumPy, so that no step is hidden, and are then shown with scikit-learn (and PyTorch in Section 4.8). All data either ship with scikit-learn and scikit-image or are generated by the code, so no downloads are needed.

## Getting started

```
pip install -r requirements.txt
jupyter lab            # then open chapter_1/chapter_1.ipynb
```

or run a single example from inside its folder:

```
cd chapter_4
python example_4_2.py
```

Run scripts from inside their own folder: figures are saved next to the script, and Example 4.8 imports `example_4_2.py` from the same folder. PyTorch is needed only for Examples 4.9 and 4.10. The notebooks also run on Google Colab after the repository has been cloned.

Dependencies: Python 3.9 or later, NumPy, SciPy, Matplotlib, scikit-learn, scikit-image, Pandas, joblib, and (optional) PyTorch. The materials were last tested with Python 3.13, NumPy 2.5, SciPy 1.18, scikit-learn 1.9, scikit-image 0.26, Matplotlib 3.11 and PyTorch 2.15. Small numerical differences can appear with other versions or on a GPU.

## Using the materials in a course

The nine notebooks follow the order of a one-semester course (about 14 weeks):

| Weeks | Notebook |
|---|---|
| 1 | `appendix_A` (Python refresher, optional) |
| 1–2 | `chapter_1` |
| 3–4 | `chapter_2` |
| 5–6 | `chapter_3` |
| 7–8 | `chapter_4` |
| 9–10 | `chapter_5` and `appendix_B` |
| 11–12 | `chapter_6` |
| 13–14 | `chapter_7` |

Shorter courses can use subsets: chapters 1–5 with Appendix B for a machine-learning course, or chapters 2–4 for an introduction to deep learning for medical images. A good classroom pattern is to run an example live, then ask students to change one parameter (the number of neighbours, the learning rate, the crossover rate) and predict the result before running it again.

## Important note

The medical examples are for education only. The fuzzy rules, thresholds and models are not clinically validated and must not be used for diagnosis or treatment.
