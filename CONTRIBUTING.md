# Contributing, reporting problems, and getting help

Thank you for using these materials.

**Report a problem.** If an example fails, gives a different result from the one described, or contains an error, please open an issue on GitHub. Include the example number, your operating system, your Python version, and the output of `pip list | grep -E "numpy|scipy|scikit|matplotlib|torch"`.

**Ask a question.** Questions about using the examples in a course are welcome as GitHub issues with the label `question`.

**Contribute.** Corrections, clearer comments, new exercises, and translations of the notebooks are welcome as pull requests. Please keep each example runnable on its own, keep the random seeds so that results stay reproducible, and run the changed script before submitting.

By contributing, you agree that your code is released under the MIT licence and your text and figures under CC BY 4.0.

Please be respectful in all discussions.
